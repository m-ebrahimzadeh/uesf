## 1. Purpose
Maintain the canonical identity, scope definition, operating topology, and active baseline metadata of the Universal Engineering Skills Framework (UESF) project.

## 2. Scope
Applies to the UESF initiative as a whole across both the Strategic Workspace and Engineering Workspace.

## 3. Rules and Requirements
1. **Project Identity**:
   * **Project Name**: Universal Engineering Skills Framework (UESF)
   * **Current Version**: `0.2.0` (Milestone M2 — Universal Agent Role Skills & Templates)
   * **Current Phase**: Milestone M2 Released (`v0.2.0` accepted on `main` at `ff33485`); Milestone M3 (Platform Adapters) eligible to begin, not yet started
   * **Founding CTO & Chief Architect**: Activated (CTO Role, Autonomy Level `A2` for routine governance / `A3` for human-gated decisions)
2. **Confirmed Scope Boundaries**:
   * **In Scope (Initial Framework)**: Universal operating model, capability model, governance/security/Git/verification/knowledge policies, multi-agent interaction protocols, and eight universal engineering agent role Skills (`CTO`, `Architect`, `Developer`, `QA`, `DevOps`, `Security`, `SRE`, `Documentation`).
   * **Out of Scope (Mission 001)**: Individual agent role Skill authoring (scheduled for Mission 002), platform-specific adapters (scheduled for Mission 003), and project-specific integrations such as PoliSDK or PoliTicket (scheduled for Mission 004+).
3. **Dual-Environment Operating Topology**:
   * **Strategic Workspace**: Gemini 4 Argon with connected Shared Workspace (`UNIVERSAL ENGINEERING SKILLS` Gemini Notebook & Google Workspace). Used for strategy, architecture, governance, task creation, knowledge curation, and deliverable review. Local filesystem/terminal/Git (`CAP-FS`, `CAP-TERM`, `CAP-GIT`) are `UNAVAILABLE` in this workspace.
   * **Engineering Workspace**: Antigravity inside VS Code (Gemini 4 Hydrogen primary coding agent; Gemini 4 Argon Orchestrator / Gemini 3.8 Flash optional). Used for local filesystem operations, Git workflows, testing, and implementation execution.
